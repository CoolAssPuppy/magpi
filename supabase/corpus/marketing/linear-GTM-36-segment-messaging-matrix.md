## Description

The panel gave us six segments. The positioning page gives us one argument in one order. Right now every brief we write picks an entry point into that argument by instinct and then somebody senior overrules it in a review, which is a slow way to have the same conversation six times.

Write the matrix. One row per segment, one entry point into the four point argument, one lead fold state, one lead finish, and the channel that carries it. Then every brief starts from a row instead of from a blank page.

Constraints, so nobody has to re-derive them:

- The four points and their order do not change. Segments change where you enter, not what is true.
- Segment names never leave the building. Agencies working on the launch get them, nobody else does.
- Nothing about durability lands in a row until the claims page is signed.
- No comparison to a named competitor in owned channels, for any segment.

Done when Maya has it on a page and Jane has read it.
